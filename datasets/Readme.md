# Datasets

This directory contains the datasets used for training and evaluating the proposed routing framework.

All datasets are generated using the MATLAB script [`congestion_dataset_for_all_3_datasets.m`](https://github.com/Mohit-Kumar-Thakur/ML-Driven-Utility-Based-Hybrid-VLC-RF-Routing-for-Congestion-Aware-UAV-Assisted-VANETs/blob/main/datasets/congestion_dataset_for_all_3_datasets.m), which generates datasets for all three scenarios.

The script provides a unified and reproducible approach to dataset generation for the proposed congestion-aware, utility-based hybrid VLC-RF routing framework.
